# SPP TPQ Nurul Hidayah Batung

Aplikasi SPP: data santri, tagihan bulanan, pembayaran, tunggakan, kuitansi, laporan.

- Frontend: HTML/CSS/JS statis (tanpa build), hosting GitHub Pages
- Database: Supabase (proyek `tpq-spp`), skema di `supabase/migrations/`
- Kunci di `js/config.js` adalah *publishable key* (aman). Jangan pernah menaruh service_role/secret key di repo.
- Peran: admin (ubah data), kepsek (hanya lihat).
